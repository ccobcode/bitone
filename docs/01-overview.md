# 产品定义

BitOne 是私钥永不联网的多链钱包。

## 1. 组成

- **手机客户端（冷钱包，Android）**：离线，储存密钥，负责核对和签名。
- **网页端（浏览器）**：联网，只持有公钥，提供全部交互，构建要签名的内容。所有钱包数据只保存在用户自己的浏览器里，不需要账号。
- **网关（服务端）**：无状态，提供订阅（WebSocket）、查询信息和代理广播，不保存任何用户数据，也不鉴权。

冷钱包和网页端之间唯一的通道是二维码。

## 2. 核心能力

1. **配对与收款**：冷钱包创建钱包，导出公钥二维码。网页端扫码导入，看到余额。收款地址可以在冷钱包核对，冷钱包也能直接显示收款码。
2. **转账**：网页端构建交易。冷钱包扫码、核对、签名。网页端扫回签名，核验后广播，实时跟踪最终性。
3. **防误签**：授权、权限变更、无法识别的合约调用，在冷钱包上都能被看见并被拦一道。

## 4. 功能

**冷钱包**

- 离线环境自检。
- 创建或导入助记词，支持 12 词和 24 词，验证备份后才能使用，可选 BIP39 密码。
- 多链账户派生。
- 导出观察钱包二维码，一次导出全部账户。
- 显示收款码，核对收款地址。
- 扫码解析交易：识别风险类别，展示完整元信息，原始数据可展开。
- 每次签名输入 PIN，高风险交易需要长按确认。
- 展示签名结果二维码。
- 离线更新内置清单。

**网页端**

- 首次打开引导：扫码连接冷钱包，或导入备份。一次扫码同时配好主网和测试网。
- 余额与交易历史，通过 WebSocket 实时更新。
- 收款：显示地址，引导到冷钱包核对。
- 发起转账、展示待签名二维码、扫回签名并核验、广播、跟踪最终性。
- 加速和取消已广播的交易。
- 地址簿。
- 本地数据管理：持久化、加密备份导出和导入、清除。
- 标志右侧的标签切换主网和测试网，只换查看的余额。

**网关**

- HTTP 查询接口，WebSocket 订阅推送，广播。
- 不存储，不鉴权，有请求上限和限流。

## 5. 不支持

- 冷钱包联网，或在冷钱包上显示余额。
- 网关或任何服务端保存用户数据、公钥、私钥。
- 鸿蒙 NEXT。
- 指纹签名。
- 在日常手机上运行冷钱包。
- DApp 连接（WalletConnect 等）、消息签名、兑换、多签、NFT。
- iOS 客户端。扩展路径见[技术方案 §3](08-tech-stack.md#3-ios-扩展路径)。
