# 界面规范

两端共用同一套设计语言和令牌。令牌只有一个来源 `design/tokens.json`，由它生成网页端的 CSS 变量和 Android 的主题，两端都不允许写死颜色、尺寸、时长和缓动。线性图标的路径同样只有一个来源 `design/icons.json`。颜色来自品牌标志，两端相同。网页端只在 `web` 段单独定义桌面按钮高度和图表颜色，只进 CSS。

技术栈不同，交互、动效和风格要一致。同一个概念在两端用同一个规格：看起来一样，按下去一样，返回和关闭的行为一样。只有鼠标和桌面宽度才需要的东西可以不同。

## 1. 设计语言

气质是安静、精确、有分量。参考现代金融和生产力应用的做法，靠留白和层次说话。

1. **边界清楚**：两端都用色调分层，卡片不画边框，层次来自 `bg`、`surface`、`surface-2` 的明度差和柔和的阴影。网页端只有输入框和顶栏保留细线。两端的列表都不画分隔线，靠行距分组，按下或悬停时显示底色。
2. **一条边线**：同一屏里所有内容的左右边缘落在同一条线上。标题、卡片、按钮、底部导航都对齐这条线。
3. **一屏一个主角**：每屏只有一个最重的元素，通常是金额或标题。其余信息降低字重和颜色，不靠粗体制造层次。
4. **技术信息收进详情**：派生路径、Chain ID、Nonce、Gas 这类内容不出现在首页和列表，只在核对详情里出现。列表第二行显示缩短的地址，用户看得懂的才放外层。冷钱包核对页的元信息一项都不能少，见[安全设计 §2.7](04-security.md#27-交易风险识别)。
5. **签名端只显示该看的**：冷钱包的核心是保管密钥，第一屏只放核对需要的金额、对方、网络、风险和手续费。其余字段放在默认折叠的「详情」里，一项不少，高风险交易默认展开。
6. **动效说明因果**：动效用来告诉用户东西从哪来、到哪去，不做装饰。

所有文字与背景的对比度不低于 4.5:1。

### 2.2 字体

- 西文和数字：Inter，全局开启等宽数字（`tabular-nums`），金额才能上下对齐。
- 中文：Noto Sans SC。
- 地址、哈希、路径：JetBrains Mono。等宽字体只用在这些地方，金额和普通数字不用。
- 字体文件打包进应用和网页，不依赖系统字体。
- 字重只用 400、500、600。标题 600，正文和标签 400，强调 500。不用 700。
- 24 及以上的字号字距收紧 1%。

| 令牌 | 字号 | 行高 | 用途         |
| ---- | ---- | ---- | ------------ |
| `t1` | 12   | 16   | 徽章、辅助   |
| `t2` | 13   | 20   | 标签、说明   |
| `t3` | 15   | 24   | 正文、按钮   |
| `t4` | 17   | 24   | 区块标题     |
| `t5` | 20   | 28   | 卡片主数值   |
| `t6` | 24   | 32   | 页面标题     |
| `t7` | 32   | 40   | 总资产       |
| `t8` | 40   | 48   | 核对页主金额 |

### 2.3 间距、圆角、阴影

- 间距：4、8、12、16、20、24、32、40、48、64，不用其他值。
- 圆角：两端相同。8（徽章内、桌面的小按钮）、12（输入框、按钮、列表行）、16（卡片、列表组、下拉菜单）、24（弹层）、全圆（胶囊）。
- 阴影：`elevation-1` 给卡片，`elevation-2` 给悬浮导航和提示，`elevation-3` 给弹层。深色模式靠明度分层，卡片不用阴影。

## 3. 主题

- 两端都只有深色，没有主题切换。
- 二维码在任何情况下都是白底深色码点，保证可扫。
- 相机取景区域永远是深色。
- 品牌图标不随界面变化。

## 4. 布局

### 4.1 网页端

- **外壳**：顶栏吸顶，`surface` 底，下方一条 `line` 细线。顶栏内容和页面内容落在同一个居中的框里，最大宽度 1200，左右内边距 24，手机上 16。标志的左边缘和卡片的左边缘对齐，钱包切换的右边缘和卡片的右边缘对齐。
- **顶栏**：高 64。左边标志、网络标签和导航，右边依次是待处理、连接状态和延迟、钱包切换。网络标签和延迟宽度固定，切换网络和数字变化时其他内容不移动。待处理平时不出现，有事时才占位置。
- **手机**：宽度小于 960 时顶栏高 56，只留标志、网络标签、待处理的数字、连接状态和延迟、钱包切换。导航放到底部标签栏，和桌面相同的四项：资产、交易记录、地址簿、冷钱包，规格见 4.4。主按钮高 52，其余可点元素高度不小于 44，输入框字号 16。
- **子页面**：导航的选中态留在父级。宽屏时标题行是父级链接加当前对象，手机上是返回图标加标题，和冷钱包的标题栏相同。
- **转账**：转账和签名是子页面，父级是资产。步骤放在页头右侧，是数字圆点加短连线，走过的步骤换成对勾，不单独占一行。手机上只有圆点，步骤名就是页面标题。广播后落到交易详情，步骤接着显示：第三步等待时圆点外扩光圈，确认后变绿写完成，失败变红。
- **浮层**：网址带参数打开（`?receive=`、`?connect=1`、`?import=1`、`?export=1`、`?edit=`），页面不动，关掉回到原处，浏览器返回也能关掉。全部浮层和确认框用同一套样式：宽屏居中，圆角 24，手机上从底部升起，高度跟内容走，软键盘弹出时跟着上移。内容比一屏高时可滚动，操作区贴着底部。手机上按钮等分，放弃在左，确认在右。
- **选择器**：宽屏贴着触发它的元素展开，手机上是底部弹层，有标题和关闭按钮，当前项用 `accent-soft` 底色。真正的菜单（钱包切换）始终贴着触发它的元素。
- **收款**：单列。二维码居中，手机上铺满内容宽度，地址、网络、告示和按钮共用左右边线，按钮等分。宽屏时账户列表放在左边，手机上换成顶部的选择器。
- **页头**：所有页面一样高，宽屏内容 32，手机 44，放页面标题或子页面的父级链接。首页也有标题。首个区块从同一条线开始，切换导航时内容不跳。
- **内容**：12 栏栅格，内容宽度 704 以上分栏，栏距 20。以下单栏，间距 16。首页宽度 896 以上才分左右两栏。
- **卡片**：一层，`surface` 底，没有边框，圆角 16，内边距 24，内容宽度 704 以下 16。标题和下面的列表间距 8，表单和其他内容间距 16。卡片不嵌套，嵌在里面的 Section 只保留内容。
- **设置行**：一行一项，左边标题和说明，右边值或操作，都贴卡片内边距。行间没有分隔线。放开关的行整行都能点。手机上输入框和成组的按钮独占一行，铺满卡片。
- **输入框**：一圈 `line-strong` 细线。聚焦时边框换成 `accent-text`，外加一圈 `accent-soft`。
- **列表**：全站一个规格 `ListRow`。左边图标 32，中间标题 `t3` 和一行说明 `t2`，右边值，数字右对齐。行高 56，没有横线，悬停或按下显示 `surface-2` 圆角底色，按下同时缩放。整行可点时带箭头。行内操作在宽屏上悬停才出现。
- **底部操作**：放在内容流的末尾，和内容右边缘对齐，主操作在最右。

### 4.2 冷钱包

- **边线**：左右边距统一 16（令牌 `gutter`），和网页端手机上相同。标题、卡片、按钮、底部导航全部对齐。
- **结构**：系统状态栏安全区、标题区、可滚动内容区、吸底操作区或底部导航、系统导航栏安全区。
- **标题区**：返回按钮的图标左边缘对齐边线，标题紧随其后。一级页面用左对齐大标题 `t6`。
- **列表组**：`surface` 圆角 16 的整块，内部没有分隔线，行高 56。
- **吸底操作区**：内容滚动到下方时用 `bg` 渐隐过渡，不画分隔线。
- **主按钮**：高 52，通栏对齐边线。次要操作用文字按钮。按钮禁用时两端都是 `surface-3` 底加 `text-3` 字，危险按钮是 `danger-soft` 底加 `danger` 字。
- **弹层**：画在同一窗口里，从底部升起，上方圆角 24，标题加关闭按钮，确认操作放弃在左，确认在右。遮罩、关闭按钮和返回键都能关。

### 4.4 底部导航

- 冷钱包三项：钱包、收款、设置。扫码是动作，不是页面，放在首页的主入口上。网页端手机上四项，见 4.1。
- 两端同一规格：悬浮胶囊，高 56，左右对齐边线，没有边框，用 `elevation-2`。下方的内容用 `bg` 渐隐，不和按钮叠在一起。
- 图标在上，文字 `t1` 在下，选中态用一整块 `accent-soft` 底色同时包住图标和文字，底色块在项目之间滑动。
- 未选中项也显示文字，切换时布局不跳动。

### 4.5 二维码

- 白底紧贴二维码，四周至少留 2 个码元的静区，不再放其他内容。
- 手机上外框铺满内容宽度，宽屏时边长 297。屏幕很矮时（横屏）按屏幕高度收窄，一屏看得全。
- 帧进度放在白底外面，与二维码等宽，每帧一段，当前帧是主色，右侧显示帧序号。超过 40 帧画不下时换成一条连续的进度条。
- 动态二维码可以暂停、调速、全屏。速度有标准、慢、快三档，间隔 500、1000、250 毫秒，来自令牌。全屏时返回键先退出全屏。
- 动态二维码换帧不做任何过渡，半透明的中间帧扫不出来。
- 外框边长固定，不随二维码版本变化，切换账户、切换地址、换帧时页面不跳。码元取整数像素，放不满的部分是白边。
- 还没有内容时用同样大小的骨架占位。收款页的地址按最长的地址留高度，宽屏两行，手机三行。

### 4.6 地址显示

- 列表里用短格式 `0x7a3F…9C21`。
- 需要核对的地方显示完整地址，4 个字符一组，用等宽字体。奇数组用 `text`，偶数组用 `text-2`，不加底色块。`0x` 连着前 4 位算第一组，两端分段相同，用户才能逐段对比。

### 4.7 PIN 键盘

键盘不贴屏幕两边，拇指够不到边缘。整块居中，靠近屏幕下方。

| 项目   | 规格                                                    |
| ------ | ------------------------------------------------------- |
| 按键   | 直径 72 的圆，`surface` 底色，按下 `surface-2`          |
| 间距   | 横向 24，纵向 16                                        |
| 整块   | 宽 264，高 336，水平居中，距底部安全区 64，矮屏 32      |
| 数字   | `t7`（32）字重 400，等宽数字，在圆内光学居中            |
| 删除键 | 和数字键同样大的触控区，无底色，图标 24，中心对齐第三列 |
| 提交键 | 需要手动提交时放在左下角空位，同样是 72 的圆键          |
| 圆点   | 直径 12，间距 16，未输入 `line-strong`，已输入 `accent` |
| 组合   | 标题、圆点、提示成一组，彼此间距 12，距键盘 32          |
| 矮屏   | 屏幕高度不足 700 时按键缩到 64，间距按比例缩小          |

### 4.8 扫码页

- 全屏相机，深色。顶部只有关闭按钮，中间是取景框，框下一句提示。
- 不放底部面板和说明卡片。
- 取景框两端同一规格：边长 260，四个角臂长 44、线宽 4，一条主色的扫描线上下来回。网页端的取景区域比手机屏幕矮，边长按高度收。
- 多帧时框下的提示换成细进度条和帧序号。已经开始收帧后，镜头里混进别的码不算失败，继续等下一帧，收到的进度不作废。
- 收齐后短促震动并直接进入下一页。网页端只在支持震动的手机浏览器上震动。

## 5. 动效

令牌：`fast` 120、`normal` 220、`slow` 360 毫秒，列表错开 `stagger` 30 毫秒。缓动 `emphasized` 用于进入，`standard` 用于状态变化，`exit` 用于离开。下表里的距离和比例也是令牌，两端相同。

| 场景     | 动效                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------- |
| 按下     | 缩放到 0.97，`fast`，松开用 `emphasized` 回到原位，`normal`                                    |
| 悬停     | 底色渐变，`fast`                                                                               |
| 页面前进 | 新页从右侧 24 滑入并淡入，旧页淡出并左移 8，`normal`                                           |
| 页面返回 | 方向相反                                                                                       |
| 选中切换 | 分段选择和底部导航的底色块滑到新位置，`normal`，不是原地变色。网页端顶部导航的选中线从中间展开 |
| 开关     | 圆点滑动，轨道变色，`normal`                                                                   |
| 列表进入 | 逐项淡入上移 8，错开 30，最多错开 8 项                                                         |
| 展开折叠 | 高度和透明度同时过渡，`normal`                                                                 |
| 弹层     | 上移 8，从 96% 放大并淡入，`normal`，遮罩 45% 同时淡入                                         |
| 提示     | 淡入上移 8，`normal`，5 秒后淡出                                                               |
| 数值变化 | 新值淡入，不做滚动计数，避免金额出现中间值                                                     |
| PIN 输入 | 圆点填入时弹一下。错误时左右抖动并短促震动                                                     |
| 长按签名 | 底色从左向右填满，3 秒匀速，松手回退。完成时震动                                               |
| 完成     | 对勾描线，`slow`，外扩一圈光                                                                   |
| 等待上链 | 进度条有光扫过，当前的圆点外扩光圈，循环。不用转圈                                             |
| 后台下载 | 页面标题右边显示「下载中」，图标的箭头往托盘里落，循环。不占内容的位置，列表不跳               |
| 加载     | 骨架屏一条光带匀速扫过，周期 1440 毫秒，不用转圈                                               |

- 系统开启减少动态效果时，位移和缩放都去掉，只保留淡入淡出。
- 金额和地址不能有动画中间值，用户看到的数字必须始终是真实值。
- 动效不能拖慢操作：动画进行中可以继续点击。

## 6. 图标库

- 代币和网络图标用 [web3icons](https://github.com/0xa3k5/web3icons)（MIT 协议），用带底色的版本，裁成圆形。
- 两端都从同一批 SVG 生成图标资源，本地打包。
- 代币在非原生链上时，右下角加网络角标，例如 TRON 上的 USDT。
- 内置清单里查不到的代币显示虚线问号图标。规则见 [安全设计 §2.8](04-security.md#28-图标和代币信息不是信任依据)。
- 界面功能图标统一用线性图标：线宽 1.8，圆角端点，24 网格。

## 7. 移动端适配

目标 SDK 35 及以上的应用强制全面屏显示（edge-to-edge），各厂商的状态栏高度、挖孔位置、导航方式都不一样，所以：

- 顶部和底部安全区一律从系统的 WindowInsets 读取，不写死任何高度。
- 需要处理的区域：状态栏、显示屏缺口（挖孔、刘海、水滴）、导航栏（手势条或三键）。冷钱包只用内置键盘，不处理系统输入法。
- 背景铺满到屏幕边缘，内容和可点击元素留在安全区内。
- 底部操作按钮放在导航栏安全区之上。
- 横屏和折叠屏：内容区最大宽度 560 居中，二维码按屏幕高度收窄。Android 16 在大屏上会忽略竖屏锁定，所以不靠锁定方向。
- 展示二维码和扫码时保持常亮，离开页面后恢复。展示二维码时自动调到最高亮度。自动亮度开关只管亮度，不影响常亮。
- 系统字号最大按 1.3 倍算，再往上按钮和底部导航放不下。
- 返回键先关最后打开的弹层或全屏二维码，都关了才离开页面。

测试矩阵至少覆盖：

| 组合             | 代表机型                        |
| ---------------- | ------------------------------- |
| 挖孔加手势导航   | 小米、三星、vivo、OPPO 近年机型 |
| 刘海加三键导航   | 较早的全面屏机型                |
| 无缺口加三键导航 | 低端机、平板                    |
| 折叠屏           | 内屏和外屏各一次                |

## 8. 文案

- 不用「·」等符号分隔信息，用排版分开：标签和值分行、独立的徽章、表格列。
- 不用分号，一句话只说一件事。
- 文字只放在四种位置：标题、标签和值，字段说明，告示，空状态。不放没有归属的说明句，解释功能或重复界面信息的句子不写。
- 字段说明紧贴它说明的字段或设置行。
- 要用户确认的操作用确认浮层 `Confirm`，异常状态用 `StateCard`，提醒一句话用 `Notice`。不做内联展开的提示块。
- 这些规则两端都适用。告示用 `Notice`，是带图标的色块，贴着它说明的内容，放在区块标题下面或操作按钮上面。只写用户要停下来看的事，错误和警告都是告示，不写裸文字。
- 每个区块最多一句说明。同一条安全提示只在关键步骤出现一次。
- 按钮文案 2 到 6 个字，用动词开头。
- 不宣称设计做不到的事。取消不等于作废，核对通过不等于资金到账，具体见[安全设计 §7](04-security.md#7-残余风险)。
- 中文用全角标点。
- 状态提示只说用户看到的结果和能做什么，不说内部机制：写「Bitcoin 余额暂时不可用。」，不写查询、地址发现、轮询、网关、节点、上游。错误提示能重试时写「请稍后重试」。
- 网页端称「网页端」，手机端称「冷钱包」。

## 9. 多语言

- 两端支持中文和英文，默认跟随系统语言，用户选过之后以选择为准。网页端在设置页切换，未配对时在欢迎页切换，切换时重新加载页面。冷钱包在设置页切换，立即生效。
- 词典是 `design/i18n.json`，以中文原文为键，由它生成两端的词典文件。`{0}` 是动态内容的占位。
- 数据层保持中文原文：核心库返回的文案、存进 IndexedDB 的时间线备注都不翻译，核对逻辑靠它们判断，只在显示时翻译。译不出来就显示原文。
- 冷钱包的文字都经过 `Txt`，在那里翻译。助记词和地址不翻译。
- `make check-copy` 检查所有文案都有英文，漏译时失败。

## 10. Web App

网页端可以添加到 iOS 和安卓的主屏幕，以独立窗口运行，不使用 Service Worker，页面始终来自网关。

- `index.html` 声明 `theme-color`、`mobile-web-app-capable`、`apple-mobile-web-app-*`、`apple-touch-icon` 和 `manifest.webmanifest`。清单的 `display` 是 `standalone`。
- 状态栏是 `black-translucent`，页面延伸到状态栏后面。顶栏让开 `safe-area-inset-top`，底部标签栏让开 `safe-area-inset-bottom`，横屏时左右边线让开刘海。
- 不回弹，不放大，点击没有灰块。
- 独立窗口没有浏览器的前进后退，每个页面都能靠顶栏、底部标签栏或页内按钮离开，每个浮层都有明确的退出。
- iPhone 没有全屏接口，二维码的全屏按钮不显示。
- iOS 上主屏幕 Web App 和 Safari 的存储互相独立，添加后要重新配对。

## 11. 通知

只为新发生、且和用户有关的事打扰他，一笔交易最多响一次。

| 事件             | 声音     | 页面             | 后台系统通知 |
| ---------------- | -------- | ---------------- | ------------ |
| 第一次发现转入   | 上行双音 | 提示，写明确认中 | 有           |
| 转入最终确认     | 无       | 列表状态更新     | 无           |
| 自己的转账已上链 | 轻单音   | 提示             | 有           |
| 转账失败或过期   | 低沉单音 | 提示，不自动消失 | 有           |
| 连接断开或恢复   | 无       | 顶栏状态         | 无           |

- **只通知新事件**：只有推送带来的新记录才通知，判断依据是本地原来没有这条记录。快照、翻页和地址发现带来的历史不通知。增量补回来的记录合成一条。
- **过滤**：清单外代币、零金额和价值低于 1 美元的转入不通知，这类转账常被用来做地址投毒。
- **合并**：屏幕上已有转入提示时并进这一条，3 秒内不重复响。
- **多标签页**：发现事件的标签页负责声音和系统通知，其他标签页只显示。
- **静默**：签名和扫码时只记录，结束后再提示。显示收款二维码时照常提示。测试网不发声。
- **内容**：提示只用来跳转查看，不带任何操作，不放完整地址。确认前写明确认中。系统通知默认不带金额，它可能出现在锁屏或屏幕共享里。
- **默认值**：提示默认打开，声音和后台提醒默认关闭。第一次收到转入时问一次，系统通知的权限也在这时才请求。
- **声音**：用 Web Audio 合成，不需要音频文件，CSP 没有放开媒体来源。
- **停留**：普通提示 5 秒后消失，鼠标悬停、聚焦或页面在后台时不计时。
