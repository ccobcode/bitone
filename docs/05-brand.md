# 品牌设计

颜色、字体等设计令牌见 [界面规范](06-ui.md)。

## 1. 图标

**概念：两端之间，只有一个比特。**

图标是两个括号夹着一个比特，贴合产品的核心动作：扫码。

| 部分   | 形态                             | 含义                                     |
| ------ | -------------------------------- | ---------------------------------------- |
| 左括号 | 圆头线条                         | 冷钱包：离线，私钥只在这一侧             |
| 右括号 | 圆头线条                         | 网页端：联网，只有公钥                   |
| 比特   | 品牌蓝圆角方块，图标里唯一的彩色 | 唯一穿过气隙的数据，也就是 BitOne 的名字 |
| 空隙   | 两个括号永不相接                 | 气隙                                     |

两个括号同时也是扫码取景框的两条边。线条用圆头，与界面里的线性图标是同一种语言。

### 构造

在 160 × 160 的画布上：

| 项目           | 数值            |
| -------------- | --------------- |
| 线宽           | 12              |
| 标志外框       | 96 × 80，居中   |
| 比特           | 28 × 28，圆角 7 |
| 括号内缘到比特 | 22              |
| 图标圆角       | 36              |

### 尺寸

- 48 px 及以上用标准版。
- 32 px 及以下自动换成粗线版：线宽 20，比特 36，外框 120 × 100，宽高比和标准版相同，保证标签页里看得清。
- 商店图标：512 × 512 满版，圆角由系统裁切。
- Android 自适应图标：标志落在 66dp 安全区内。

### 版本

| 版本         | 用途                       |
| ------------ | -------------------------- |
| 深色（主版） | 启动器、应用商店           |
| 浅色         | 放在深色照片或深色印刷底上 |
| 品牌蓝       | 营销物料，比特改为墨色     |
| 单色         | 印刷、钢板刻印             |
